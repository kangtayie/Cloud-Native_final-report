# 4단계 배포 가이드: 음성 입력 (Amazon Transcribe)

리전은 **서울(ap-northeast-2)** 입니다. "내 언어"로 말하면 글자로 바꿔 입력칸에 넣어 줍니다. 잘못 인식된 부분은 사용자가 고친 뒤 번역합니다.

```
브라우저(녹음) → POST /transcribe → stt-lambda → S3 녹음 버킷(stt/) 저장 → Transcribe 작업 시작 → jobId 응답
브라우저 → 3초마다 GET /transcribe/{jobId} → stt-lambda → 인식 결과 → 입력칸에 채움
```

따라 말하기(3단계)와 구조가 같지만 **기능이 다르므로 람다·IAM 역할·S3 폴더를 분리**합니다 (MSA, 최소 권한). 녹음 버킷 `local-speak-rec-2026`은 3단계에서 만든 것을 그대로 씁니다 (수명주기 1일 삭제가 `stt/`에도 적용됨).

## 0. 비용
따라 말하기와 같습니다: Transcribe 1회 약 $0.0015 (서울 $0.0001/초, 최소 15초 과금). 새 상시 과금 리소스 없음.

## 1. IAM 역할 `role-stt-lambda`
1단계와 같은 방법(AWS 서비스 → Lambda → `AWSLambdaBasicExecutionRole`)으로 만들고, 인라인 정책 `transcribe-s3-stt-minimal`을 붙입니다.
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["transcribe:StartTranscriptionJob", "transcribe:GetTranscriptionJob"],
      "Resource": "*"
    },
    {
      "Effect": "Allow",
      "Action": ["s3:PutObject", "s3:GetObject"],
      "Resource": "arn:aws:s3:::local-speak-rec-2026/stt/*"
    }
  ]
}
```
- 따라 말하기 역할은 `practice/*`, 이 역할은 `stt/*`만 접근합니다. 같은 버킷이어도 서로의 녹음을 읽을 수 없습니다.

## 2. Lambda `stt-lambda`
| 항목 | 값 |
|---|---|
| 함수 이름 | `stt-lambda` |
| 런타임 | **Python 3.12** |
| ARM64 아키텍처 | 켜기 |
| 사용자 지정 실행 역할 | 켜기 → `role-stt-lambda` |
| 지속적인 실행, EC2 용량 공급자, 함수 URL, VPC | **모두 끔** |

생성 후:
1. 코드 탭 → `lambda_function.py`에 `lambdas/stt_lambda.py` 전체 붙여넣기 → **Deploy**
2. 구성 → 일반 구성 → 제한 시간 **0분 10초**
3. 구성 → 환경 변수 → `RECORD_BUCKET` = `local-speak-rec-2026`
4. 테스트 이벤트 (비용 없음):
   ```json
   {"requestContext": {"http": {"method": "GET"}}, "pathParameters": {"jobId": "abc"}}
   ```
   → Response의 `statusCode: 400` + "작업 ID가 올바르지 않습니다." 이면 성공

## 3. API Gateway 경로 2개
1. `local-speak-api` → **경로** → **생성** → `POST` `/transcribe`
2. **생성** → `GET` `/transcribe/{jobId}`
3. `/transcribe`의 POST → **통합 연결** → 새 통합: Lambda → `stt-lambda` (페이로드 2.0)
4. `/transcribe/{jobId}`의 GET → **통합 연결** → **기존 통합 선택**에서 `stt-lambda` 통합
5. CORS는 3단계에서 GET을 이미 추가했으므로 변경 없음

## 4. 프론트 갱신
1. 웹사이트 버킷 `local-speak-web-2026` → 새 `frontend/index.html` 업로드
2. HTTPS 주소로 접속: `https://local-speak-web-2026.s3.ap-northeast-2.amazonaws.com/index.html`
