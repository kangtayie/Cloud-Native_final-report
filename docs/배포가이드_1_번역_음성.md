# 1단계 배포 가이드: 번역 + 원어민 음성

리전은 모두 **서울(ap-northeast-2)** 로 통일합니다. 콘솔 오른쪽 위 리전이 "아시아 태평양(서울)"인지 먼저 확인하세요 (콘솔 기본값이 버지니아 북부일 수 있음).

## 0. 비용 알림 먼저 걸기 (AWS Budgets)
크레딧 없는 계정이라 리소스를 만들기 전에 알림부터 겁니다. 예산 2개까지는 무료입니다.
1. Billing and Cost Management → **Budgets** → 예산 생성 → "월별 비용 예산" 템플릿
2. 금액 **$5**, 알림 받을 이메일 입력 → 생성

## 1. IAM 역할 2개 만들기 (권한 최소화)
| 역할 이름 | 붙일 정책 |
|---|---|
| `role-translate-lambda` | `AWSLambdaBasicExecutionRole` + 인라인 정책: `translate:TranslateText`, `comprehend:DetectDominantLanguage` |
| `role-tts-lambda` | `AWSLambdaBasicExecutionRole` + 인라인 정책: `polly:SynthesizeSpeech`, `polly:DescribeVoices` |

> 교재처럼 `TranslateFullAccess`를 붙여도 동작하지만, 필요한 권한만 주는 쪽이 보고서에서 보안 설계 근거가 됩니다.

인라인 정책 예시 (번역용):
```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["translate:TranslateText", "comprehend:DetectDominantLanguage"],
    "Resource": "*"
  }]
}
```

인라인 정책 예시 (음성용):
```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["polly:SynthesizeSpeech", "polly:DescribeVoices"],
    "Resource": "*"
  }]
}
```

## 2. Lambda 함수 2개 만들기
| 함수 이름 | 런타임 | 코드 | 실행 역할 | 제한 시간 |
|---|---|---|---|---|
| `translate-lambda` | Python 3.12 | `translate_lambda.py` 내용 붙여넣기 | `role-translate-lambda` | 10초 |
| `tts-lambda` | Python 3.12 | `tts_lambda.py` 내용 붙여넣기 | `role-tts-lambda` | 10초 |

- 핸들러는 기본값 `lambda_function.lambda_handler` 그대로 두고, 콘솔의 `lambda_function.py`에 코드를 붙여넣은 뒤 **Deploy**를 누릅니다.
- 제한 시간은 구성 → 일반 구성에서 기본 3초를 10초로 늘립니다. Polly 첫 호출이 3초를 넘을 수 있어요.

## 3. API Gateway (HTTP API) 만들기
1. API Gateway → **HTTP API** 생성 → 이름 `local-speak-api`
2. 경로(Route) 추가
   - `POST /translate` → 통합: `translate-lambda`
   - `POST /speak` → 통합: `tts-lambda`
3. **CORS** 설정
   - Allow origin: `*` (최종 제출 때는 S3 웹사이트 주소로 좁히기)
   - Allow methods: `POST, OPTIONS`
   - Allow headers: `content-type`
4. 스테이지 `$default`(자동 배포) → **호출 URL**을 복사합니다.
5. **(필수) 스로틀링 설정:** 스테이지 `$default` → 기본 경로 설정의 제한(Throttling)을 **속도 2, 버스트 5**로 설정합니다. (처음엔 1/2였으나 정상 사용도 429에 걸려 2026-11-16 상향)
   - 한도를 넘은 요청은 람다·Translate·Polly까지 가지 않고 `429`로 거절되므로 비용이 생기지 않습니다.
   - 이 값은 경로마다 따로 적용됩니다. 최대 길이 요청이 계속 들어와도 시간당 비용 상한은 `/translate` 약 $54, `/speak` 약 $29입니다(초당 5건이면 약 5배).
   - 시연·채점 규모(몇 명이 몇 초에 한 번 클릭)에는 충분합니다. 거절되면 화면에 "잠시 후 다시 시도해 주세요"가 표시됩니다.

## 4. 프론트엔드 (S3 정적 웹 호스팅, 교재 5.5와 동일)
1. `index.html`의 `API_BASE`를 3-4에서 복사한 호출 URL로 바꿉니다.
2. S3 버킷 생성 → 퍼블릭 액세스 차단 해제 → 버킷 정책으로 읽기 공개
   ```json
   {
     "Version": "2012-10-17",
     "Statement": [{
       "Effect": "Allow",
       "Principal": "*",
       "Action": "s3:GetObject",
       "Resource": "arn:aws:s3:::<버킷 이름>/*"
     }]
   }
   ```
   읽기(`GetObject`)만 공개하고, 업로드·삭제 권한은 열지 않습니다.
3. `index.html` 업로드 → 속성 → 정적 웹 사이트 호스팅 활성화 (인덱스 문서 `index.html`)
4. 엔드포인트 주소(`http://<버킷 이름>.s3-website.ap-northeast-2.amazonaws.com`)로 접속해서 테스트합니다.

> 콘솔 Lambda **테스트** 탭에서 먼저 확인하고 싶으면 아래 이벤트를 쓰세요 (HTTP API 형식).
> ```json
> {"requestContext": {"http": {"method": "POST"}}, "body": "{\"text\": \"기숙사 행정실이 어디에 있나요?\", \"source\": \"ko\", \"target\": \"pl\"}"}
> ```
> `tts-lambda`는 body를 `{\"text\": \"Dzień dobry\", \"lang\": \"pl\"}`로 바꿔서 테스트합니다.
